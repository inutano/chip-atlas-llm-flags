# ChIP-Atlas LLM Flags

This repository extracts structured metadata from BioSample JSON files and classifies them into disease, treatments, and gene-modification flags. The system uses large language models to analyze biological sample descriptions and automatically categorize experimental conditions, enabling systematic analysis of ChIP-seq datasets and their associated biological contexts.
